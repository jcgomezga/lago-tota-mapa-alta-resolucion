# Estructura ecológica e hidrológica — Cuenca del Lago de Tota

Sitio estático para visualizar una vista previa y descargar la versión de máxima resolución del mapa.

## Archivo de máxima resolución

Colocar la imagen final exactamente en:

`assets/mapa/MAPA_EEP_LAGO_TOTA_FULL.png`

El sitio ya apunta a esa ruta tanto en el botón de descarga como al hacer clic sobre la vista previa.

## GitHub Pages

Publicar desde la rama `main`, carpeta `/ (root)`.
